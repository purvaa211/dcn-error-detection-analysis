Error Detection Techniques Guide

Mathematical formulations, detection guarantees, and working principles of the four canonical schemes.

Linear 1D Parity

Parity Check (VRC)

Vertical Redundancy Check appends 1 parity bit to ensure the total number of '1' bits is even (or odd). Minimum Hamming distance d_min = 2.

Detection Guarantee: 100% of single-bit errors and all odd-number error counts. Blind Spot: Any even number of bit errors (2, 4, 6...) completely escapes detection. Redundancy: Exactly 1 bit per frame.
2D Block Parity

Longitudinal Redundancy Check (LRC)

Partitions data into fixed 8-bit blocks (rows) and computes column-by-column parity bits, forming a Block Check Character (BCC).

Detection Guarantee: All single-bit errors and burst errors within a single block. Blind Spot: Even number of errors occurring in the exact same column position across different rows. Redundancy: 1 byte (8 bits) of BCC plus block alignment padding.
Arithmetic 1's Complement

Internet Checksum (1's Complement)

Divides data into m-bit segments (default 8 bits; 16 bits for RFC 1071), sums them with end-around carry wrapping, and complements the result.

Detection Guarantee: High detection for random errors; catches single-bit errors across all segments. Blind Spot: Transposed words or compensating errors (+k in one word and -k in another). Redundancy: Exactly 8 or 16 bits.
Polynomial Division (GF(2))

Cyclic Redundancy Check (CRC)

Treats bitstreams as polynomials over GF(2). Appends r zeros, divides by generator G(x) using XOR modulo-2 division, and transmits remainder.

Detection Guarantee: 100% of single-bit errors, all odd errors (if G has (x+1) factor), all burst errors of length ≤ r. Blind Spot: Error polynomials E(x) that are exact multiples of G(x) (probability ≈ 2^-r). Redundancy: Exactly r bits (8 bits for CRC-8, 16 for CRC-16, 32 for CRC-32).

Comparative Performance Analysis

Simultaneously evaluate all four techniques on identical payload and synchronized channel error conditions.

Technique Overhead (Bits / %) Processing Latency Corrupted Positions Detection Status Final Verdict
Click Run Synchronized Comparison to evaluate all four schemes concurrently.

1. Parity Parity Invariance

Simple 1D Parity (d_min=2) will always fail to detect any even number of corrupted bits (2, 4, 6...) regardless of payload size.

2. LRC Matrix Orientation

LRC catches bursts within a block, but fails when 2 errors hit identical column indices in different blocks.

3. Checksum Arithmetic Bounds

Checksum detects single-bit errors and bursts, but has blind spots if corruptions swap entire words or cancel out algebraically.

4. CRC Polynomial Superiority

CRC provides deterministic 100% protection against all burst errors ≤ generator degree r, and misses random errors with probability ~2^-r.
